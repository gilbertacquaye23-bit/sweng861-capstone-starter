# SWENG 861: Capstone Flagship Project 
# StratSight
## Healthcare Strategic Decision Support
StratSight is a full-stack healthcare strategic decision-support application developed for the SWENG 861 Software Construction course.

## Project Overview   
Healthcare financial analysts often collect financial, operational, market, capacity, and performance information from multiple spreadsheets and reports when evaluating service- line opportunities. StratSight will provide a structured application where analysts can create strategic assessments, calculate selected indicators, review dashboard results, and submit assessments for leadership review.

## Target Users
- Financial Analysts
- Directors
- Executive Reviewers

## Planned Core Features
- Secure user authentication
- Role-based access control
- Create, read, update, and delete strategic analyses - Strategic metric calculations
- Decision dashboard
- DRIFT API executive interpretation
- Leadership review and commenting workflow
- Analysis status and history
## Architecture
StratSight will use a modular monolith architecture with separate frontend, backend, and database layers.

Technology Stack
• React
• JavaScript
• Node.js
• Express.js
• MongoDB
• Mongoose
• REST and JSON
• DRIFT Inference API
• Jest and Supertest

• Docker
• GitHub Actions
Security and Data Scope
StratSight will use sample or non-sensitive business data. It will not store patient information or protected health information. API credentials and other secrets will be stored in environment variables and excluded from the GitHub repository.
